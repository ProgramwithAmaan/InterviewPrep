# InterviewPrep

A small project containing interview question examples and practice notes for MERN stack topics.

This repository includes simple web examples and study prompts designed to help practice common MERN interview topics like:

- MongoDB data modeling and queries
- Express API design and routing
- React component structure and state management
- Node.js runtime and server-side JavaScript

Files included:

- `index.html` — page structure and markup
- `style.css` — styling rules and visual layout
- `script.js` — interactive behavior and script examples

Use this project as a quick reference for MERN stack interview preparation and small demo tasks.
